Roteamento entre os ISPs: BGP

● No BGP, os pacotes não são roteados para um
endereço de destino específico, mas para prefixos
a. Sub-redes
● A tabela de repasse terá linhas no formato (x, I)
a. x é um prefixo
b. I é uma interface

● O BGP fornece um meio de
a. Obter informações de alcançabilidade do prefixo
de ASs vizinhos
b. Determinar as melhores rotas até os prefixos

● Cada roteador, ou é um roteador de borda ou roteador
interno
a. Um roteador interno se conecta diretamente
apenas a hospedeiros e roteadores do seu
próprio AS

Anúncio de rotas BGP
● Pares de roteadores trocam informações via conexões
TCP (conexões BGP)
● Uma conexão que envolve dois ASs é uma conexão
BGP externa
● Uma conexão que envolve roteadores no mesmo ASs é
uma conexão BGP interna

● São muitos caminhos possíveis na Internet
a. Como a escolha é feita?
● Atributos BGP são associados a um prefixo para
definir uma rota
a. AS-PATH
i. Evita laços
b. NEXT-HOP

BGP: Determinando
as melhores rotas
● A rota escolhida é a com menor custo até o próximo
NEXT-HOP
● A ideia é tirar os pacotes o mais rápido possível do
próprio AS
● Trata-se de um algoritmo egoísta
